# Contributing (Week 7)

- `main` is always working and protected. Work on short-lived branches: `feat/<topic>`, `fix/<topic>`, `docs/<topic>`.
- Open a pull request for every change; another member reviews before merging.
- Commit messages follow Conventional Commits, e.g. `feat(clearance): block Registrar until offices sign`.
- Never commit `.env` or `node_modules/`. Update `.env.example` when you add a setting.
- Disclose AI help in `docs/AI_DEVELOPMENT_LOG.md` and read every AI-written line before committing.
